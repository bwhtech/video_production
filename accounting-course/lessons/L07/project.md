## Kit gaps / workarounds (shared kit untouched)
- `L7.tagChip` / glyphs / entry / lock / trays / bank belong in the kit (L8 reuses the chips; L6's Bank asset is missing from `cast.js`).
- No `dizzy` rig expression → spirals are overlay discs on `m.head` (head-local ±21, −54).
- Never tween scale + x/y on ONE node with `svgOrigin:"0 0"` when the node's coordinates are relative to a translated wrapper and several tweens overlap (s05 cards) — split into a `pos` node (x/y) and a `body` node (scale/opacity).
- `K.dropIn` tweens `scale` — never use it on a node that carries a `transform` attribute (cast rigs `ravi.g` / `meera.g`): fade them with opacity instead.
- Layout lint: device chips / pile cards put several texts tightly together → `data-layout-allow-overlap` via `L7.allow(root)`.
- JS cue words: names with an apostrophe need it in the anchor (`@meera's`, `@gopal's`, `@isn't`).
