## Anchors approach (Hindi-first)
- Every cue is an `@name` = the **English word** of that segment's English text (nth occurrence), put in `vo-segments.hi.json` as `{@name}` / `{@name#2}` immediately before the Hindi word where the beat lands; `{p@name}` on the sentence-final Hindi word for every `pauses.json` entry (all 30 of them, nth preserved: `@thousand#2`, `@hundred#2/#3`, `@depreciation#2`, `@credit#2`).
  `python3 ../../tools/hi_anchors.py --lang hi` → `anchors.hi.json` (208 anchors, 0 problems). The English build later resolves the same names with no scene/sfx/pauses changes.
- Gotchas: a `{p@x}` marker only creates the key `@x|p`, so a scene cue on the same name needs its own `{@x}` too (`{@adjustments}{p@adjustments}`, `{@expense}{p@expense}`, `{@yes}{p@yes}`, `{@ones}{p@ones}`…). Pause markers sit on the sentence-final token with `।`/`?` (`…{p@used}हुए।`, `…{p@paid}जाए।`). Running-total beats use hyphenated English tokens as names (`@thirty-five`, `@twenty-five`, `@twenty-four`). Hindi keeps accounting terms Latin (journal, adjustments, accrual, expense, Stock, asset, liability, payable, book value, depreciation, Debit/Credit …) and ₹ amounts as spoken numbers; catchphrase "कौन सी दो चीज़ें बदलीं?" (s03d, s04d, s05c, s08a); "आपकी बारी… जवाब अगले lesson की शुरुआत में।"
- Helper scripts (scratch): a cue/anchor linter (every `cue("sXX","@w")` in scenes + sfx exists in `anchors.hi.json`) — run after every script edit.
